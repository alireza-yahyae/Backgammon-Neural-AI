### My AI. Your Next Backgammon Challenge.

A backgammon project built around my own AI.

I integrated my AI into an existing backgammon game based on Horatiu's original project, creating a single-player experience where you can challenge my AI.

**The game is the environment. The AI is the focus.**

![Gameplay Preview](preview.png)

## 🧠 The AI

The main focus of this project is my own backgammon AI. The game provides a playable environment in which users can experience it firsthand.

## 🎮 Play Against the AI

Play as white against the computer-controlled opponent.

The game includes dice rolling, legal moves, animated piece movement, undo, and reset functionality.
